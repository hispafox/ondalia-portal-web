# Portal de pedidos de Distribuciones Ondalia

Las tiendas piden aquí su reposición sin llamar al almacén. Son tres páginas en HTML y una hoja de estilos. No se compila ni se instala nada.

## Cómo se abre

- **En el navegador:** doble clic en `index.html`.
- **En Visual Studio 2026:** **Archivo** → **Abrir** → **Carpeta** y elige la carpeta del repositorio.
- **En Visual Studio Code:** **File** → **Open Folder** y elige la carpeta del repositorio.

## Qué hay en cada fichero

| Fichero | Qué es |
|---|---|
| `index.html` | La página de inicio |
| `catalogo.html` | El catálogo, con el precio por caja y las existencias |
| `pedido.html` | Un pedido de ejemplo, con su total y el aviso que ve la tienda al confirmar |
| `css/estilos.css` | Los estilos de las tres páginas |
